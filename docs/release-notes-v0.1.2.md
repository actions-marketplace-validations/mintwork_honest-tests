# honest-tests v0.1.2

A maintenance release: no changes to what honest-tests detects or reports.

- The README on npm now shows the same badges as GitHub (the downloads badge, which showed
  "package not found or too new" for the brand-new package, is gone for now).
- Published from GitHub Actions with npm trusted publishing (OIDC) and signed provenance; no npm
  token exists for this package.

```bash
npx @mintwork/honest-tests audit .
```
